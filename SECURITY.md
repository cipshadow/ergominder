# Security

Download Ergominder only from this repository's [Releases](https://github.com/cipshadow/ergominder/releases) page and verify the supplied SHA-256 checksum.

To report a security issue, use GitHub's private vulnerability reporting for this repository. Do not open a public issue with exploit details or personal information.

Ergominder 1.0.0 is ad hoc signed and is not notarized or verified by Apple. Its installer never asks you to disable Gatekeeper. Future installers preserve the installed app's quarantine attribute, so macOS checks the app separately before first launch. It does not require administrator access, install system-wide files, download dependencies, or make network requests.
